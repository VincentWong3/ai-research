# 人工智能问题树

**从思想的形式化到开放世界智能**

一份以问题为线索的人工智能知识地图。它不按流派或年份编排，而是从“系统在处理什么、怎样处理、凭什么相信、怎样改进”这些共同问题出发，把表征、计算、推理、学习、行动与评价连接起来。

[在线阅览](https://vincentwong3.github.io/ai-research/) · [完整地图](docs/map.md) · [版本记录](CHANGELOG.md) · [许可证](LICENSE)

## 这份地图回答什么

人工智能的方法看起来差异很大：证明定理、从图像中识别物体、预测事件、让机器人完成任务。沿着这些任务继续追问，会遇到两个共同的基础问题：对象怎样表示，过程怎样执行。二者结合之后，又会分成两种问题情境。

**给定形式框架中的求解（Formal World）**：对象、模型类、规则或目标已经明确，研究系统能够推导、推断、搜索、规划和学习到什么程度。概率模型、棋类、规划问题和自动证明都属于这一类；框架明确并不意味着没有不确定性，也不意味着没有学习。

**开放世界中的认知、学习与行动（Open World）**：现实可能超出当前表示、假设或模型，系统需要感知、发现规律、修正模型、主动获取信息，并在反馈中行动。这里的核心不是“换一种算法”，而是框架本身的检验与修订。

全图以一条主线组织：

> 人工智能的核心困难，不是把某个任务形式化，而是当现实超出既有框架时，系统如何发现、检验并修正框架；计算扩展性只是其中一类困难，而且不是开放世界独有的。

## 结构

| 层次 | 核心问题 | 主要内容 |
|---|---|---|
| I · 表征 | 什么进入计算？怎样表示才有用？ | 对象、语言、意义、知识组织、连续表示与表征评价 |
| II · 计算 | 怎样执行变换？什么算得了、算得动？ | 算法、证明、可计算性、复杂性与通用求解机制 |
| III-A · 给定形式框架 | 框架明确后能做什么？ | 演绎、概率、搜索、规划、决策与形式框架中的学习 |
| III-B · 开放世界 | 框架不足时怎么办？ | 感知、发现、模型学习、计算改善、主动获取、行动、终身适应、多主体与评价 |

地图共 33 个章级节点、603 个编号节点。R 表示表征，C 表示计算，F 表示给定形式框架，O 表示开放世界。编号用于查阅，不表示历史先后。

## 如何阅读

- **先看主线**：从“0. 问题怎样一步步展开”开始，理解概念为什么出现，以及问题怎样分叉。
- **按分支查阅**：从“2. 完整问题树”进入 R/C/F/O 的任一章；每个节点采用“问题 → 简短回答、关键词或代表理论”的形式。
- **按问题横向阅读**：第 3 节的章级导学和第 5 节的横向联系，适合把分散的知识连成线。

在线站点提供侧栏目录、可折叠的问题树、搜索与明暗主题。Markdown 版本适合引用、检索与版本比较。

## 为什么是问题树

这份地图不是方法目录。每一个章级节点都尽量回答三个问题：它为什么出现，已有的回答是什么，又留下了什么困难。树形结构只是导航；真实的知识关系包含大量交叉，因此第 5 节专门列出横向联系。编号是索引，不是历史的顺序，也不是流派的边界。

## 边界

这是一份技术认识论地图，重点在表征、计算、推理、学习、行动与评价。它不展开社会伦理、认知神经科学和具体工程实现；语言、具身与多主体作为开放世界循环的一部分处理，不单独划分流派。地图会继续修订：新增分支、合并节点和修正归类都会记录在版本记录中。
